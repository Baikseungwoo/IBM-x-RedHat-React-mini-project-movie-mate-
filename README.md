# 🎬 Movie Mate

> IBM x RedHat 부트캠프에서 진행한 React 기반 영화 정보 미니 프로젝트

`Movie Mate`는 React를 활용해 영화 관련 정보를 탐색하고 화면에 구성하는 미니 프로젝트입니다.  
프론트엔드 프로젝트에서 API 데이터를 화면에 연결하고, 컴포넌트 기반으로 UI를 구성하는 흐름을 연습하는 데 초점을 두었습니다.

<br />


## 📌 프로젝트 소개

이 레포지토리는 IBM x RedHat 부트캠프 과정 중 진행한 React 미니 프로젝트입니다.

영화라는 친숙한 주제를 바탕으로 데이터를 가져오고, 사용자에게 보기 좋은 화면으로 보여주는 프론트엔드 개발 흐름을 학습했습니다.  
단순히 React 문법을 사용하는 것에서 끝나지 않고, 팀 프로젝트 방식으로 브랜치를 나누고 각자 맡은 파트를 구현하는 협업 방식도 함께 연습했습니다.

처음 보는 사람도 이 레포지토리를 통해 다음 내용을 파악할 수 있습니다.

- React 기반 미니 프로젝트 구조
- 영화 정보 서비스를 주제로 한 화면 구성
- 컴포넌트 단위 UI 개발 방식
- Git 브랜치를 활용한 팀 협업 흐름
- 부트캠프 과정에서 진행한 실전형 프론트엔드 실습

## 🚀 실행 방법

프로젝트를 클론합니다.

```bash
git clone https://github.com/Baikseungwoo/IBM-x-RedHat-React-mini-project-movie-mate-.git
```

프로젝트 디렉터리로 이동합니다.

```bash
cd IBM-x-RedHat-React-mini-project-movie-mate-
```

의존성을 설치합니다.

```bash
npm install
```

개발 서버를 실행합니다.

```bash
npm run dev
```

프로젝트 구조에 따라 실제 React 앱이 하위 폴더에 있을 수 있으므로, 실행 전 `package.json` 위치를 확인하면 됩니다.

## 👥 협업 방식

이 프로젝트는 팀 단위로 진행되었으며, 각자 브랜치를 나누어 작업하는 방식을 사용했습니다.

```bash

git branch -r
git switch <branch-name>
```

작업 시 `main` 브랜치는 직접 수정하지 않고, 각자 맡은 브랜치에서 기능을 구현하는 방식으로 진행했습니다.
